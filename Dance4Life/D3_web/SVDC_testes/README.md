
# Dance4Life — SVDC Dashboard Presentation

## Features
- Professional D3.js dashboard
- Portuguese / English language toggle
- Uses all provided datasets
- Responsive layout
- Data story approach for oral presentation

## Included Visualizations
1. Top users by engagement score
2. Invitation status distribution
3. Activity timeline
4. Activity by city
5. Recommendation clusters
6. Behavioral correlation scatterplot

## Run
Open `index.html` using VSCode Live Server or any local server.
